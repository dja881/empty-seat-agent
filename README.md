# Empty Seat Agent

Razorpay × ISB AI PM Build Challenge, Track 2 (Recover and Grow with AI).

An AI growth agent that sells a salon's unfilled chair time to its own customers, the way airlines
sell their last seats. It agrees a plan with the owner each morning, sends one-to-one offers in the
receptionist's name, negotiates within the owner's limits, and locks each slot the moment the
customer pays through Razorpay.

Demo salon: Strand & Co., Madhapur, Hyderabad. All data is synthetic.

## Stack

- Next.js on Vercel (screens and server routes holding secret keys)
- Supabase: Postgres, Realtime, Storage
- Qwen on Cerebras (OpenAI-compatible API) for the three agents
- Razorpay test mode: Orders API, Checkout, `payment.captured` webhook, Refunds API
- ElevenLabs for the agent's voice; browser speech recognition for the merchant

## Run locally

```bash
npm install
cp .env.example .env.local   # then fill in the server-side keys
npm run dev
```

## Data

- `supabase/migrations/0001_schema.sql`: tables
- `supabase/migrations/0002_reset_demo.sql`: `reset_demo()`, generated by `scripts/gen-seed.mjs`
- `supabase/migrations/0003_static_history.sql`: 90 days of history, area network signals, benchmarks, bank offer

`select reset_demo();` restores the seeded day (calendar, slots, settings, demo clock, simulator).
